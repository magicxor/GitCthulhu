# Contributing to GitCthulhu

GitCthulhu is under construction; please open an issue to discuss a change before sending a pull request.

- Read [DEVELOPMENT.md](DEVELOPMENT.md) to build and test, and [AGENTS.md](AGENTS.md) and
  [crates/AGENTS.md](crates/AGENTS.md) for the engineering rules.
- Keep changes focused. Run `cargo fmt`, `cargo clippy --workspace --all-targets` and the tests of the crates you
  touched.
- Commit messages: a short imperative subject, then why and impact.
- Code inherited from GitButler is under the Functional Source License, see [LICENSE.md](LICENSE.md); contributions
  are accepted under the same terms.
